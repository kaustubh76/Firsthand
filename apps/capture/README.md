# firsthand-capture

Minimal PWA: enrol a passkey with the WebAuthn `prf` extension, tap to unlock the locker, stamp a
capture with a `DEVICE_CAPTURE` passport, view anchored batches, post a rescission commitment.

Memory adapters until Phase 2/4 wire the deployed contracts; the verbs and the refusal gate are real.
`pnpm --filter firsthand-capture dev` (WebAuthn needs `localhost` or HTTPS).
