# @firsthand/contracts

Solidity (Foundry) contracts of README §9, plus generated TypeScript ABIs and a deployments loader.

| | |
|---|---|
| Responsibility | On-chain state: principals, anchors, grants, rescissions, receipts, royalty settlement, read lens. |
| Holds secrets? | **No.** Contracts see commitments, hashes, signatures and wrap *references* only. |
| Upgradeability | **None.** Immutable deployment, no proxies, no admin keys on the serving path (README §12). |

## Layout

- `src/libraries/` — pure, independently fuzz-tested libraries (`SplitMath`, `MerkleLib`, `PassportLib`,
  `AuthorityDigests`, `EpochLib`, `P256`). Coverage gate: ≥ 95 % lines and branches (`pnpm coverage`).
- `src/interfaces/` — the protocol API each phase implements.
- `src/*.sol` — contracts. `PrincipalRegistry` (Phase 1), `PassportAnchors{Baseline,Paged}` (Phase 2),
  `Rescissions`, `GrantManager`, `ReceiptLedger`, `RoyaltyRouter` and `FirsthandLens` (Phase 3,
  ADR-0011) are complete and 100 % line-covered. No admin keys, no proxies; every authority-signed
  entry point is relayable and verifies under the contract's own EIP-712 domain (ADR-0009).
- `test/unit` (vector-driven via `stdJson`), `test/fuzz` (split conservation, anchors, router),
  `test/invariant` (router USDC balance == dust), `test/doubles` (etched RIP-7212 P-256 verifier,
  `MockUSDC` with EIP-3009 under USDC's domain), `test/fork` (`test:testnet`, needs `MONAD_RPC_URL`).
- `script/Deploy.s.sol` — writes `deployments/<chainId>.json`. Deploys `MockUSDC` when
  `DEPLOY_MOCK_USDC=true` (default on 31337), otherwise uses `USDC_ADDRESS`; `REVEAL_WINDOW_BLOCKS`
  (default 1000) and `ANCHORS_LAYOUT` (`baseline` | `paged`) select GrantManager and Lens wiring.
- `abi/` — generated by `scripts/export-abi.mjs` (`pnpm build`), committed.

## Commands

```sh
pnpm --filter @firsthand/contracts test          # forge test
FOUNDRY_PROFILE=ci forge test                     # 10k fuzz runs, deeper invariants
pnpm --filter @firsthand/contracts coverage      # lcov + gate
pnpm --filter @firsthand/contracts deploy:anvil  # needs DEPLOYER_PRIVATE_KEY, USDC_ADDRESS
```

Golden vectors live in `packages/test-vectors/vectors`; tests fail loudly if a suite is empty.
